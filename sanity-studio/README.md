# DentistaDravic Sanity Studio

Studio separado para modelar o conteudo do site da Dra. Vitoria Passos.

## Variaveis de ambiente

Crie um `.env.local` quando houver projeto Sanity real:

```txt
SANITY_STUDIO_PROJECT_ID=seu_project_id
SANITY_STUDIO_DATASET=production
```

## Scripts

```bash
npm run dev
npm run build
npm run deploy
```

Nesta etapa os schemas foram criados, mas o conteudo ainda nao foi migrado.
